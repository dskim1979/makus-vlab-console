| 사이트 | 이런 곳 | 관리 콘솔 |

| [일반 업무 VDI](general.md) | 본사 · 지점 · 재택 근무자가 어디서나 같은 업무 데스크톱에 접속하는 사무실 VDI입니다. | 메뉴 5개 · 화면 14개 |
| [대학교 실습실](university.md) | 학과 · 단과대 실습실과 수업을 위한 구성입니다. | 메뉴 6개 · 화면 15개 |
| [연구소 · 기업 R&D](research.md) | 보안 요구가 큰 연구 조직을 위한 구성입니다. | 메뉴 6개 · 화면 16개 |
| [FPGA · AI 연구실](fpgaai.md) | GPU · vGPU · MIG · FPGA · 국산 NPU를 여러 사람이 나눠 쓰는 연구실 구성입니다. | 메뉴 7개 · 화면 22개 |
